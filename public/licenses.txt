Stockfish.js 19.0.1
------------------
Files: public/engine/stockfish-19-lite-single.js and matching .wasm
Unmodified lite, single-threaded build from the stockfish@19.0.1 npm package.
Stockfish.js 19 (c) 2026, Chess.com, LLC.
Based on Stockfish (c) T. Romstad, M. Costalba, J. Kiiski, G. Linscott
and other contributors. Neural network by Chris Bao (sscg13).
License: GNU GPL version 3; see /engine/COPYING.txt.

Package containing the distributed binaries:
https://registry.npmjs.org/stockfish/-/stockfish-19.0.1.tgz
Corresponding source (fixed release):
https://github.com/nmrugg/stockfish.js/tree/v19.0.1
Release source commit: 0d5dd7944f88c817c07a26bc4fb1905d5f9c46d6
Source archive:
https://github.com/nmrugg/stockfish.js/archive/0d5dd7944f88c817c07a26bc4fb1905d5f9c46d6.tar.gz
Build instructions and scripts:
https://github.com/nmrugg/stockfish.js/blob/v19.0.1/README.md#how-do-i-compile-the-engine
https://github.com/nmrugg/stockfish.js/blob/v19.0.1/build.js
Use the release's Emscripten 6.0.9 toolchain, Node.js and make, then run:
  node build.js --single-threaded --lite
The build script obtains/verifies the NNUE network and embeds it in the WASM.
Network identified by the distributed engine: nn-61e7af4bb97d
https://tests.stockfishchess.org/nns?network_name=nn-61e7af4bb97d
Keep the matching JS/WASM files beside each other when serving the application.
